## Описание папок и файлов

### 📁 Приоритизация/

Анализирует архив объявлений с drom.ru и определяет, какие автомобили чаще всего
встречаются на дорогах России. Результат — отсортированный список марок/моделей
по частоте упоминаний, который используется для формирования топ-1600.

| Файл | Описание |
|---|---|
| `prioritize_v3.py` | Читает архив drom.ru (CSV/Parquet), считает частоту каждой марки/модели/поколения, сохраняет в `priority_export.csv` |
| `analyze_chunked.py` | Вспомогательный скрипт для обработки большого архива по кускам, если он не помещается в память целиком |
| `priority_export.csv` | Итоговая таблица: марка, модель, поколение, количество объявлений, доля от общего парка |
| `Priority_export_sorted.xlsx` | То же, что `priority_export.csv`, но отсортированное по убыванию частоты, оформленное в Excel для удобного просмотра |

---

### 📁 Датасет/

Формирует финальный список топ-1600 автомобилей на основе результатов приоритизации.
Топ-1600 — это минимальный набор марок/моделей/поколений, который покрывает 98.26%
всех автомобилей на дорогах России.

| Файл | Описание |
|---|---|
| `build_mvp_top1600.py` | Берёт `priority_export.csv`, отбирает автомобили пока покрытие не достигнет 98%+, добавляет колонки для габаритов (пустые), сохраняет результат в `MVP_dataset_restored.xlsx` |
| `MVP_dataset_restored.xlsx` | Итоговый датасет: 1 600 строк, каждая строка — отдельное поколение/рестайлинг автомобиля с полем для длины, ширины, высоты, колёсной базы и клиренса |

---

### 📁 Габариты/

Заполняет габариты для каждого автомобиля из датасета, используя открытые источники:
Wikipedia (EN, RU, JA) и Wikidata. Скрипты работают последовательно — каждый
добирает то, что не нашёл предыдущий.

| Файл | Описание |
|---|---|
| `fill_dimensions.py` | Первый проход: ищет длину/ширину/высоту в Wikipedia EN и RU для каждой строки датасета, заполняет найденные значения в `MVP_dataset_restored.xlsx` |
| `fill_holes_v2.py` | Второй проход: добивает пропуски через Wikipedia EN → RU → JA (для японских марок) → Wikidata SPARQL. Сохраняет прогресс в `_holes_v2_progress.json`, можно прерывать и возобновлять |
| `retry_misses.py` | Третий проход: повторно пробует автомобили, для которых первые два скрипта ничего не нашли — с расширенными запросами и альтернативными написаниями |
| `MVP_dataset_restored.xlsx` | Датасет с заполненными габаритами (актуальная версия, результат всех трёх скриптов) |
| `_holes_v2_progress.json` | Файл прогресса для `fill_holes_v2.py` — список уже обработанных строк, чтобы при перезапуске не начинать заново |

### 📁 3Д_модели/

Скрипты для поиска и скачивания 3D-моделей с Sketchfab, их масштабирования
под реальные габариты и сборки финального индекса. Запускаются по порядку, шаг за шагом.

| Файл | Описание |
|---|---|
| `build_asset_candidates.py` | Читает `cars_dataset/metadata/models_index.csv` и создаёт таблицу `asset_candidates.csv` — список всех автомобилей со статусом `search_needed`, для которых ещё нужно найти модель |
| `discover_sketchfab_assets.py` | Ищет 3D-модели на Sketchfab по API для каждого автомобиля из `asset_candidates.csv`. Оценивает результаты по совпадению марки/модели/года, сохраняет лучшие варианты обратно в CSV. Нужен `SKETCHFAB_TOKEN` |
| `download_sketchfab_assets.py` | Скачивает найденные модели с Sketchfab по UID из `asset_candidates.csv`. Распаковывает архивы, сохраняет путь к файлу в `IMPORTABLE_PATH.txt`. Поддерживает `--limit 20` для соблюдения дневного лимита API |
| `select_best_external_assets.py` | Из всех скачанных вариантов для каждого автомобиля выбирает лучший по качеству (high/medium/low) и детализации (количество треугольников). Сохраняет в `best_external_models.csv` |
| `batch_fit_all_vehicles.py` | Запускает Blender в фоне для каждой модели и масштабирует её под реальные длину/ширину/высоту из датасета. Результат — `.blend`-файлы в `cars_dataset/external_fitted/` |
| `build_final_models_index.py` | Собирает финальную таблицу `final_models_index.csv`: для каждого автомобиля — путь к его `.blend`-файлу, UID на Sketchfab, габариты и статус |

### 📁 3Д_модели/cars_dataset/

Создаётся автоматически при запуске скриптов. В репозитории не хранится.

| Папка | Что появится после запуска |
|---|---|
| `metadata/` | CSV-таблицы с результатами каждого шага: кандидаты, лучшие модели, финальный индекс |
| `external_fitted/` | Готовые `.blend`-файлы, масштабированные под реальные габариты. Схема имён: `марка__модель__поколение__рестайлинг__uid8.blend` |

## Почему 3D-модели не хранятся в репозитории

3D-файлы занимают **~98 ГБ** — GitHub не принимает файлы больше 100 МБ,
а весь репозиторий ограничен несколькими гигабайтами.

Кроме того, все модели уже существуют на Sketchfab — загружены их авторами.
Хранить копии в репозитории не имеет смысла: любой может скачать их
напрямую с Sketchfab с помощью скриптов из папки `3Д_модели/`.

Это стандартная практика для больших датасетов — в репозитории хранятся
только **код и метаданные**, а сами файлы воспроизводятся по инструкции.

## Как скачать 3D-модели со Sketchfab

### Что нужно

- Python 3.10+
- Аккаунт на [sketchfab.com](https://sketchfab.com)
- API-токен: `sketchfab.com → Settings → Password & API → Generate token`
- Blender 3.0+ (для подгонки размеров)

### Установка зависимостей

```bash
pip install requests openpyxl pandas beautifulsoup4 duckdb
```

### Порядок запуска скриптов

Все скрипты запускаются из папки `3Д_модели/`. Можно использовать любой терминал —
PowerShell, CMD, встроенный терминал VS Code или любую другую IDE.

**Шаг 1. Сформировать список кандидатов**

```bash
python build_asset_candidates.py
```

**Шаг 2. Найти модели на Sketchfab**

Перед запуском нужно задать API-токен как переменную окружения:

```bash
# PowerShell
$env:SKETCHFAB_TOKEN = "ВАШ_ТОКЕН"

# CMD
set SKETCHFAB_TOKEN=ВАШ_ТОКЕН

# Linux / macOS
export SKETCHFAB_TOKEN=ВАШ_ТОКЕН
```

Либо создать файл `.env` в папке `3Д_модели/` и прописать там:
```
SKETCHFAB_TOKEN=ВАШ_ТОКЕН
```

Затем запустить:
```bash
python discover_sketchfab_assets.py
```

**Шаг 3. Скачать найденные модели**

```bash
python download_sketchfab_assets.py --limit 20
```

`--limit 20` — количество моделей за один запуск.  
Sketchfab ограничивает скачивания в день — скрипт сохраняет прогресс
и продолжает с того места где остановился.

**Шаг 4. Выбрать лучшую модель для каждого автомобиля**

```bash
python select_best_external_assets.py
```

**Шаг 5. Масштабировать под реальные габариты**

```bash
python batch_fit_all_vehicles.py
```

**Шаг 6. Собрать финальный индекс**

```bash
python build_final_models_index.py
```
